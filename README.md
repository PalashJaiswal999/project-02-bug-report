# Project 02 – Bug Report

## Project Overview
Manual testing project focused on identifying, documenting and tracking software defects.

## Project Deliverables
- Detailed Bug Report
- Requirements Traceability Matrix (RTM)
- Testing Dashboard

## Testing Activities
- Functional Testing
- Negative Testing
- Regression Testing
- Defect Identification
- Defect Documentation
- Requirement Traceability

## Bug Report
Defects are documented with:
- Bug ID
- Module
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status

## Tools Used
- Microsoft Excel
- Manual Testing

## Skills Demonstrated
Manual Testing | Bug Reporting | RTM | Defect Tracking | Test Documentation
